# SlugLab

`SlugLab` is a small side project built alongside the URL shortener course.

It is a simple C# console app used to practice:

- slug generation
- URL validation
- short-link creation
- click count simulation

## What It Demonstrates

- turning a title into a URL-friendly slug
- preventing duplicate slugs with a simple suffix strategy
- storing short links in memory
- simulating redirects and click tracking

## Example Ideas

- create a slug from `My First ASP.NET Link`
- add a new destination URL
- simulate clicks and watch the counter increase

## Run

If `.NET 8 SDK` is installed:

```bash
dotnet run --project PracticeProjects/SlugLab/SlugLab.csproj
```
